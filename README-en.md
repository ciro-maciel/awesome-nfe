## Official portals

Where to find the manuals, schemas and technical notes for each document.

- [Portal Nacional da NF-e](https://go.mymarketing.click/nfe-portal-nacional-da-nf-e) - Guidance manuals, XML schemas, technical notes, and the NF-e lookup. `official` `free`
- [NFS-e Nacional](https://go.mymarketing.click/nfe-nfs-e-nacional) - The national standard for the service invoice, with the public issuer and the data environment. `official` `free`
- [NFS-e Nacional: documentação técnica](https://go.mymarketing.click/nfe-nfs-e-nacional-documentacao-tecnica) - Manuals, layouts and APIs for the national NFS-e for integrators. `official` `free` `API`
- [Portal da NFC-e](https://go.mymarketing.click/nfe-portal-da-nfc-e) - Documentation for the consumer invoice on the SVRS portal, used by several states. `official` `free`
- [Portal Nacional do CT-e](https://go.mymarketing.click/nfe-portal-nacional-do-ct-e) - Manuals and schemas for the electronic transport document (CT-e). `official` `free`
- [Portal do MDF-e](https://go.mymarketing.click/nfe-portal-do-mdf-e) - Documentation for the electronic manifest of fiscal documents. `official` `free`
- [Portal do SPED](https://go.mymarketing.click/nfe-portal-do-sped) - The Brazilian Federal Revenue's Public Digital Bookkeeping System: EFD, ECD, ECF and validator programs. `official` `free`

## PHP libraries

Open, with repository activity in 2026.

- [sped-nfe](https://go.mymarketing.click/nfe-sped-nfe) - The most used library for generating, signing and transmitting NF-e and NFC-e to the SEFAZ. `open source`
- [sped-common](https://go.mymarketing.click/nfe-sped-common) - The common NFePHP classes for NF-e, CT-e and MDF-e: certificate, signing and communication. `open source`
- [nfse-php](https://go.mymarketing.click/nfe-nfse-php) - PHP SDK for the national NFS-e. `open source` `SDK`
- [php-nfse](https://go.mymarketing.click/nfe-php-nfse) - Generation and communication of NFS-e with municipalities. `open source`
- [Cliente PHP da NFE.io](https://go.mymarketing.click/nfe-cliente-php-da-nfe-io) - NFE.io's PHP SDK for issuing NFS-e, with no dependencies. `open source` `SDK`

## Java libraries

Open, with repository activity in 2026.

- [Java_NFe](https://go.mymarketing.click/nfe-java-nfe) - NF-e and NFC-e in Java, with lookup, sending, cancellation and events. `open source`
- [wmixvideo/nfe](https://go.mymarketing.click/nfe-wmixvideo-nfe) - Electronic invoice in Java, with the complete data model. `open source`

## .NET libraries

Open, with repository activity in 2026.

- [DFe.NET](https://go.mymarketing.click/nfe-dfe-net) - Generation of NF-e and NFC-e and consumption of SEFAZ services in C#. `open source`
- [ZeusFiscal](https://go.mymarketing.click/nfe-zeusfiscal) - Issuing and printing NF-e, NFC-e, MDF-e and CT-e in C#. `open source`
- [Unimake DFe](https://go.mymarketing.click/nfe-unimake-dfe) - DLL to integrate ERPs with electronic fiscal documents. `open source`
- [OpenAC.Net.NFSe](https://go.mymarketing.click/nfe-openac-net-nfse) - Issuing and transmitting NFS-e for several municipal standards. `open source`
- [OpenAC.Net.NFSe.Nacional](https://go.mymarketing.click/nfe-openac-net-nfse-nacional) - Issuing national-standard NFS-e in C#. `open source`

## Python libraries

Open, with repository activity in 2026.

- [PyNFe](https://go.mymarketing.click/nfe-pynfe) - Interface with the NF-e and NFC-e webservice in Python. `open source`
- [nfelib](https://go.mymarketing.click/nfe-nfelib) - Python bindings for reading and generating the XML of NF-e, national NFS-e, CT-e, MDF-e and BP-e. `open source`
- [Localização brasileira do Odoo](https://go.mymarketing.click/nfe-localizacao-brasileira-do-odoo) - Brazilian fiscal modules for Odoo, including NF-e. `open source`

## Issuing APIs

Services that issue on your behalf. In alphabetical order.

- [eNotas](https://go.mymarketing.click/nfe-enotas) - Automatic issuance of NFS-e and NF-e for online sellers. `paid` `API`
- [Focus NFe](https://go.mymarketing.click/nfe-focus-nfe) - API for NF-e, NFC-e, NFS-e, CT-e and MDF-e. `paid` `API`
- [NFE.io](https://go.mymarketing.click/nfe-nfe-io) - API for issuing NFS-e and NF-e and querying tax data. `paid` `API`
- [PlugNotas](https://go.mymarketing.click/nfe-plugnotas) - Tecnospeed's API for NF-e, NFC-e and NFS-e across thousands of municipalities. `paid` `API`
- [Qive](https://go.mymarketing.click/nfe-qive) - Capture and management of received invoices, formerly called Arquivei. `paid` `API`
- [Webmania](https://go.mymarketing.click/nfe-webmania) - REST API for NF-e, NFC-e and NFS-e. `paid` `API`

Each item says what it is. The tags next to it help you choose: official when it comes from whoever defines the standard, open source when the code is published, free or paid based on the usage model, API and SDK based on how you integrate.
